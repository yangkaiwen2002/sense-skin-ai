## 本轮补齐的 AI Engineer 证据

- **模型驱动的受限工具调用**：`agent_runtime.py` 使用本地 Ollama `/api/chat`。模型通过 JSON Schema 约束输出选择市场、租买、事件、知识工具；参数经 Pydantic 校验，研究范围和金额来自用户验证后的请求。没有任意 HTTP、Shell、交易或写账户工具。
- **可控编排**：最多四轮工具决策，每种工具只执行一次；外层 240 秒截止时间。行情、租买与知识覆盖检查可在模型漏选时明确补充，轨迹会标注“覆盖检查”，不会冒充模型选择。
- **Schema 输出与修复**：结构化报告经 `ResearchReport` 校验；模型选择受限证据编号，服务端填入原文并验证逐字匹配，判断中的数字必须出现在对应引文中。最多一次修复，仍有不支持的解释时丢弃该解释，并明确降级为来源原文摘录；结构或证据编号仍不合法时不发布报告。
- **可审计执行**：保存实际模型调用次数、返回 token 数、耗时、来源、工具错误、报告校验与修复结果。运行统计来自数据库，不使用填充数字。
- **数据契约与隔离**：Mock 数据明确标注，Mock 刷新不联网、不伪造新采集时间；生产适配器仍可切换。演示启动器使用独立 SQLite 文件。
- **交付验证**：新页面与客户端契约使用 TypeScript；Vitest 验证真实交互和数据边界；Docker Compose 定义本地隔离服务；CI 执行类型、测试、构建、检索回归。

结构校验只证明格式和引用可追溯，不证明语义蕴含或排除了全部模型幻觉。小模型对复杂、多饰品长问题的质量需要更大评估集持续验证。

## 尚未完成，不能写成已经实现

1. **生产数据**：BUFF、租赁平台的授权数据源、稳定采集 SLA、费率、押金与成交深度未齐备；当前验收环境按要求使用 Mock。
2. **生产账户体系**：没有登录、租户隔离、服务端自选同步、共享权限、个人数据删除流程。API 是单用户本地服务，不能直接公开到互联网。
3. **通知后台**：目标价检查在自选页面打开时发生，没有定时推送、邮件或手机通知服务。
4. **企业 Agent 平台**：此仓库没有 AWS Bedrock AgentCore、Strands、Composio OAuth 或 Nexus 的企业多租户实现。它们属于其他工作经历，不应混写进本项目。
5. **可靠性运营**：缺少生产级集中日志/Tracing、监控告警、备份演练和并发压测。SQLite additive migration 适合本地单进程；生产需正式迁移与数据库方案。
6. **质量评估**：静态知识库尚未逐条独立核验，历史价格与收益描述不能用于交易判断。已有检索回归与 Agent 故障/校验测试；免费小模型的解释可能被校验拒绝并降级为原文摘录；没有大规模生成质量、人类偏好、交易收益或长期 Agent 成功率评估。
7. **容器验收**：提供 Compose/Dockerfile；本机没有 Docker，未宣称完成容器启动验收。Mac 推荐原生 Ollama 获得 Metal 加速。
8. **前端迁移范围**：新增页面/契约为 TypeScript，既有页面仍保留 JSX；不是全仓 TypeScript 迁移。

## 面试演示建议

1. 搜索红线，核对演示标签、平台、采集时间；对比报价和租买成本。
2. 发起研究，展开工具调用过程，解释请求范围和模型自主选择的区别。
3. 点击结论来源，对照原文；展示错误引文或额外参数被测试拒绝。
4. 在研究库重命名、归档、恢复；下载带来源的报告。
5. 在“连接与数据”运行 24 题检索评估，解释 Recall、MRR、nDCG 与当前默认通道。
6. 清楚说明以上未完成项，避免把“个人项目可演示”说成“生产系统已上线”。
