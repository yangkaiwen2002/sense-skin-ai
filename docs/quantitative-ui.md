# 量化界面与验收 · 2026-11-27

本轮把已有 API 和研究记录转成更容易比较的数字、条形图与分布图，没有新增虚构行情或模型准确率。

| 页面 | 用户能直接看到 | 统计口径 |
| --- | --- | --- |
| 市场 | 筛选数量、中位数、价格区间、四档价格分布、采集/演示/过期覆盖 | 仅当前筛选且已载入的目录，最多 50 件；价格统计采用 24 小时内、来源类型明确的正数报价，演示单独标记 |
| 平台对比 / 详情 | 最低价、最高价、相差金额和比例、各平台相对最低价贵多少 | 同类型的新鲜报价；优先采集，没有采集时才比较演示。不把不同类型混算；比例以最低价为分母 |
| 租买 | 使用成本差额、日均成本、同尺度成本条、购买本金占预算和余额/缺口 | 租金与转卖损耗比较；购买本金单列。未知押金不视为零，不把较低使用成本当作可负担证明 |
| AI 研究 | 来源数、去重引用来源数、模型选定工具次数、模型调用耗时 | 来自持久化的本轮记录；缺失遥测显示空值。耗时仅模型调用总和，不是端到端时间；引用率不等于准确率 |

计算完成后将键盘焦点和视图移到租买结果；遵循减少动态效果设置。搜索无匹配时“清除筛选”同时清理搜索词。平台表格的最低价和溢价使用与量化卡片一致的来源过滤规则。

## 验证

- 前端类型检查通过；9 项 Node 测试 + 17 项 Vitest 测试通过；生产构建成功。
- 新增边界覆盖：混合真实/演示来源、过期/未来/缺失时间、无效报价、价格档位边界、奇偶中位数、单平台、零成本、零预算、本金不足、未知押金、重复或不存在的来源引用、缺失模型耗时。
- Chrome 实测市场搜索联动与清除空结果、详情平台统计、平台价差、七天租买计算与结果定位、已保存研究的真实记录。
- 390px 移动端实测市场、平台对比、租买和研究；文档宽度 384px，无整页横向溢出，明细表保留内部横向滚动。最后浏览器检查无 console error/warn。
- 后端业务接口与 Agent 执行逻辑未修改；本轮没有重复运行生成质量评估。

本地演示数据的可复核例子：全目录 31 件，中位数 959.87 元；搜索“红线”后 2 件，中位数 537.40 元。红线平台报价差 30.20 元、最高高出 12.0%；七天租金与转卖损耗差 0.79 元，购买本金占 1000 元预算的 25.2%。它们是演示环境结果，不是当前市场报价或投资收益。
